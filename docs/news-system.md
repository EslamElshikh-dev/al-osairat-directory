# نظام أخبار دليل العسيرات

## النتيجة الحالية

يعرض النظام الأخبار ذات الصلة بمركز العسيرات وقراه في ثلاث طبقات:

1. بطاقة مختصرة في الصفحة الرئيسية وصفحة `/news`.
2. صفحة تفاصيل داخلية ثابتة الرابط على `/news/[id]`.
3. تغطية تحريرية عربية كاملة داخل الدليل عند توافر مادة مصدرية كافية.
4. رابط مباشر وواضح إلى المقال لدى الناشر الأصلي.

صفحة التفاصيل تستخلص وقائع المادة المنشورة، ثم تنشئ صياغة صحفية أصلية متعددة الفقرات تعرض المقدمة والمتن وأبرز الوقائع والسياق المحلي وحدود المعلومات. يظهر اسم الناشر ورابط المقال وتاريخ النشر بوضوح. لا ينسخ النظام نص المقال أو صوره، ولا يعيد صياغته جملة بجملة. النص الحرفي الكامل داخل الدليل يظل مقتصرًا على المادة الأصلية للدليل أو المرخصة له.

## طريقة الربط

المصادر معرفة في `lib/news.ts` بقائمة سماح مغلقة للنطاقات الموثوقة. القنوات الحالية هي:

- صفحة موضوع العسيرات لدى اليوم السابع.
- RSS المحافظات لدى اليوم السابع.
- RSS الرسمي للمصري اليوم.
- RSS الرسمي للأزهر الشريف.

خط المعالجة:

1. يجلب الخادم HTML أو RSS عبر HTTPS فقط، بمهلة أقصاها 12 ثانية.
2. ينظف XML/HTML والنصوص قبل العرض.
3. يرفض أي رابط خارج النطاقات المسموح بها.
4. يحتفظ بالتغطيات التي تذكر العسيرات مباشرة، أو إحدى قرى المركز مع سياق سوهاج.
5. يحدد القرية والتصنيف آليًا.
6. يحذف التكرار باستخدام الرابط والعنوان المنظف.
7. يرتب الأخبار من الأحدث إلى الأقدم.
8. عند فتح صفحة التفاصيل يجلب وصف الصفحة ومتن `articleBody` من JSON-LD إن كان متاحًا، مع fallback محافظ لفقرات منطقة المقال.
9. يرسل وقائع النص المستخرج إلى Vercel AI Gateway لإنشاء تغطية أصلية من 4 إلى 7 فقرات.
10. يرفض الناتج إذا احتوى رقمًا لا يظهر في المادة المصدرية أو تطابقًا حرفيًا طويلًا معها.
11. عند فشل الاستخراج أو التوليد، يعود العرض تلقائيًا إلى الموجز الموثق دون تعطيل الصفحة.

إذا تعطل مصدر واحد، تستمر بقية المصادر ويظهر الأرشيف الموثق الاحتياطي بدل ترك الصفحة فارغة.

## كيف يتم التحديث؟

- مدة الكاش الحالية: 1800 ثانية، أي 30 دقيقة.
- بعد انتهاء المدة، أول طلب جديد للصفحة يبدأ إعادة جلب المصادر وتحديث الكاش.
- الزائر يحصل على نسخة متاحة حتى لو فشل مصدر مؤقتًا، ثم يحاول النظام مجددًا في الطلبات التالية.
- `checkedAt` يعرض وقت تنفيذ الفحص الحالي، وعدّاد القنوات يوضح عدد المصادر التي استجابت.
- التغطية المولدة تحفظ في Data Cache لمدة 7 أيام. يدخل النص المصدري نفسه في مفتاح الكاش، لذلك يؤدي تغير المادة بعد فحصها إلى إنشاء نسخة جديدة دون انتظار انتهاء السبعة أيام.

هذا تحديث تلقائي قائم على الزيارات وليس مهمة مجدولة تعمل بلا زيارات. إذا كان المطلوب تحديثًا حتميًا في الدقيقة نفسها حتى عند عدم وجود زوار، نضيف Vercel Cron آمنًا يستدعي إعادة التحقق، بعد التأكد من خطة Vercel وحدود تكرار Cron.

## سياسة النص الكامل وSEO

الأخبار المجمعة من جهات خارجية تستخدم وضع `generated-coverage` عند نجاح الاستخراج والتوليد، أو `external-summary` عند عدم كفاية المادة:

- صفحة التفاصيل تحمل `noindex,follow`.
- الرابط القانوني `canonical` يشير إلى المقال الأصلي.
- البيانات المنظمة من نوع `WebPage` مع `citation` و`isBasedOn`، وليست `NewsArticle` منسوبة للدليل.
- التغطية المولدة تذكر الناشر الأصلي وتشرح أنها صياغة مستقلة مبنية على وقائعه.
- تتحول الصفحة إلى مادة قابلة للفهرسة فقط بعد اعتمادها كمادة أصلية أو مرخصة وإضافة بيانات المحرر.

المادة الأصلية أو المرخصة تضيف `editorial` إلى الخبر:

```ts
editorial: {
  rights: 'owned', // أو licensed
  author: 'اسم المحرر',
  updatedAt: '2026-08-30T12:00:00.000Z',
  body: ['الفقرة الأولى...', 'الفقرة الثانية...'],
}
```

عند وجود نص تحريري كافٍ، يتحول العرض آليًا إلى مقال كامل قابل للفهرسة، وتستخدم الصفحة `NewsArticle` وبيانات المؤلف والناشر وتاريخ التحديث. يجب الاحتفاظ بمستند الترخيص عند استخدام `licensed`.

## محرك الصياغة

- الحزمة: AI SDK 7.
- المسار: Vercel AI Gateway، مع OIDC تلقائيًا على Vercel أو `AI_GATEWAY_API_KEY` خارج Vercel.
- النموذج الافتراضي: `openai/gpt-5-mini` ويمكن تغييره عبر `NEWS_EDITORIAL_MODEL`.
- يمكن إيقاف التوليد فورًا عبر `NEWS_EDITORIAL_ENABLED=false` دون تعطيل الأخبار أو الموجزات.
- كل طلب موسوم داخل Gateway باسم الميزة وإصدار الـprompt لتتبع التكلفة.
- المادة المصدرية تعامل كبيانات غير موثوقة، ولا يسمح للنموذج بتنفيذ تعليمات واردة داخلها أو استخدام معلومات من ذاكرته.

## إضافة مصدر جديد

قبل إضافة أي مصدر يجب التأكد من:

- وجود RSS أو API رسمي أو إذن مكتوب للاستخدام.
- ثبات الرابط ووضوح اسم الناشر والتاريخ.
- أن شروط الاستخدام تسمح بالاستهلاك المقصود.
- إضافة النطاق إلى `allowedHosts` وعدم السماح بإعادة التوجيه إلى نطاق مجهول.
- اختبار الترميز العربي، والتواريخ، والتكرار، ودقة فلترة القرى.

بعد ذلك يضاف تعريف المصدر إلى `newsSources`، ويحدد `format`، وتضاف طريقة parsing مستقلة إذا لم يكن RSS قياسيًا.

## المرحلة الإنتاجية الموصى بها

للحفاظ على الروابط والأخبار بعد خروجها من RSS، الأفضل نقل مرحلة التجميع إلى مخزن دائم:

- جدول `news_items` لحفظ الهوية والرابط والعنوان والوصف والمصدر والتاريخ والتصنيف والحالة.
- سجل `news_ingestion_runs` لمراقبة نجاح كل مصدر وزمن الاستجابة والأخطاء.
- Cron للاستيراد كل 30 دقيقة.
- مراجعة بشرية اختيارية قبل تحويل أي مادة إلى خبر أصلي كامل قابل للفهرسة.

بهذا يصبح RSS قناة إدخال، وليست قاعدة البيانات نفسها، وتظل صفحات الأخبار مستقرة حتى لو حذف المصدر العنصر من خلاصته.
