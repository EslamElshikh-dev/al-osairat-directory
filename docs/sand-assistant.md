# سَند — مساعد دليل العسيرات

## الحالة

سَند يعمل دائمًا كباحث موثّق داخل الدليل. الذكاء الاصطناعي طبقة اختيارية للصياغة فقط؛ غياب المفاتيح أو انتهاء الحصة لا يوقف البحث.

## مسار الطلب

1. فحص الطوارئ وحقن التعليمات وخروج السؤال عن النطاق.
2. بحث read-only في `search_directory_entities` عبر مفتاح Supabase العام.
3. عند تعذر Supabase، استخدام snapshot الدليل المرفق مع آخر نشر.
4. إذا توفرت الحصة والمفاتيح: Groq ثم Cloudflare Workers AI.
5. إذا فشل المزودان: قالب ثابت بصوت سَند مع نفس بطاقات النتائج.

لا يملك سَند أي أداة SQL أو مفتاح Supabase سري، ولا توجد له صلاحية كتابة. البلاغات تبقى عبر نموذج النشاط الحالي الذي يتطلب حسابًا مؤكد البريد ويمنع التكرار والإغراق.

## متغيرات Vercel

| المتغير | النوع | المطلوب |
| --- | --- | --- |
| `SAND_RATE_LIMIT_SECRET` | Secret | قيمة عشوائية بطول 32 حرفًا على الأقل؛ بدونها يعمل البحث المباشر فقط |
| `GROQ_API_KEY` | Secret | مفتاح Groq المجاني؛ اختياري |
| `GROQ_MODEL` | Config | اختياري؛ الافتراضي `qwen/qwen3.8-27b` |
| `CLOUDFLARE_ACCOUNT_ID` | Secret | مطلوب فقط لتراجع Cloudflare |
| `CLOUDFLARE_AI_API_TOKEN` | Secret | Token محدود إلى Workers AI فقط |
| `CLOUDFLARE_AI_MODEL` | Config | اختياري؛ الافتراضي `@cf/qwen/qwen3-30b-a3b-fp8` |
| `SAND_AI_ENABLED` | Config | ضع `false` لإيقاف AI مع إبقاء البحث المباشر |

لا تُستخدم متغيرات `NEXT_PUBLIC_*` لأي مفتاح AI.

## حدود الاستخدام

- 12 صياغة AI ناجحة لكل متصفح في اليوم بتوقيت UTC.
- 4 محاولات AI في الدقيقة لكل Cookie مجهولة + HMAC لبادئة IP وUser-Agent.
- لا يُخزن IP خام ولا سجل المحادثة.
- حذف Cookie قد يعيد الحد اليومي؛ حدود حسابات المزودين تبقى خط الدفاع النهائي.

## الأمان والتأريض

- نتائج قاعدة البيانات تُعامل كبيانات غير موثوقة وليست تعليمات.
- رقم أو رابط غير موجود في النتائج يؤدي إلى رفض نص النموذج والرجوع للقالب المباشر.
- الطوارئ ثابتة في الواجهة وتُعرض بلا انتظار AI أو Supabase.
- الأسئلة الطبية والسياسية وطلبات كشف التعليمات لا تُرسل إلى النموذج.
- ToolLoopAgent مجبر على قراءة أداة الدليل أولًا، ويتوقف عند 3 خطوات كحد أقصى.
